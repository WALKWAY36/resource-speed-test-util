# Resource Speed Test Util

Консольная утилита для измерения скорости скачивания
данных на Node.js.

## Требования

Node.js 22 или выше.

## Клонирование и Запуск

### 1. Клонирование

```bash
git clone https://github.com/WALKWAY36/resource-speed-test-util.git

cd resource-speed-test-util
```

### 2. Запуск

```bash
npm start -- <YOUR_URL>
```

или

```bash
node index.js <YOUR_URL>
```
