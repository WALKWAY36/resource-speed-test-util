# Internet Speed Test

Консольная утилита на Node.js для измерения скорости скачивания данных с указанного URL.

## Возможности

- Выполнение 10 последовательных HTTP-запросов.
- Потоковое скачивание данных без хранения всего файла в оперативной памяти.
- Измерение продолжительности каждого запроса.
- Расчёт общего объёма скачанных данных.
- Расчёт среднего времени запроса и скорости скачивания.
- Валидация URL и обработка сетевых ошибок.
- Таймаут 30 секунд на каждый запрос.

## Требования

- Node.js 22 или выше.
- Git для клонирования репозитория.

Сторонние зависимости отсутствуют.

## Установка

```bash
git clone https://github.com/USERNAME/internet-speed-test.git
cd internet-speed-test
```

## Запуск

```bash
node index.js <url>
```

Или через npm:

```bash
npm start -- <url>
```

### Пример запуска

```bash
node index.js "https://speed.cloudflare.com/__down?bytes=10000000"
```

Для более точного измерения рекомендуется использовать ссылки на достаточно большие файлы, например изображения или архивы.

## Пример результата

```text
========== Results ==========
Total requests: 10
Total downloaded: 100.00 MB
Total time: 20.00 s
Average request time: 2000.00 ms
Download speed: 40.00 Mbps
=============================
```

## Методика измерения

Программа выполняет 10 последовательных GET-запросов. Каждый следующий запрос начинается только после полного чтения тела предыдущего ответа.

Время измеряется с помощью `performance.now()` и включает ожидание ответа сервера и скачивание данных.

Среднее время запроса рассчитывается делением суммарной продолжительности запросов на их количество.

Скорость скачивания рассчитывается по формуле:

```text
Speed (Mbps) = (Total bytes × 8) / (Total seconds × 1 000 000)
```

### Единицы измерения

| Показатель | Единица |
|---|---|
| Объём данных | MB (мегабайты) |
| Общее время | s (секунды) |
| Среднее время запроса | ms (миллисекунды) |
| Скорость скачивания | Mbps (мегабиты в секунду) |

1 MB = 1 000 000 байт.

1 Mbps = 1 000 000 бит/с.

## Обработка ошибок

Программа завершает выполнение с ненулевым кодом выхода при возникновении ошибки:

- Отсутствие URL.
- Некорректный URL.
- Неподдерживаемый протокол.
- HTTP-ошибка.
- Ошибка сетевого соединения.
- Превышение времени ожидания запроса.

## Ограничения

Результат отражает скорость скачивания данных с конкретного сервера и зависит от его производительности, сетевой задержки и текущей нагрузки на интернет-соединение.

Служебный сетевой трафик и HTTP-заголовки не учитываются. Если сервер применяет HTTP-сжатие вопреки запрошенному `Accept-Encoding: identity`, объём распакованных данных может отличаться от фактического объёма переданных данных.
